# Bushmeck — файлы для раздачи

Репозиторий **только под готовые файлы**. Исходники клиента, сервера и лаунчера лежат в
[Pashvot/Bushmeck-26.2](https://github.com/Pashvot/Bushmeck-26.2). Здесь ничего не собирается.

## Что здесь лежит

Файлы публикуются как **Release assets**, а не в дерево git — так GitHub отдаёт их напрямую,
без расхода трафика сервера (Render) и без лимитов на размер.

Релиз с тегом `vX.Y.Z` содержит:

| Файл | Что это |
| --- | --- |
| `bushmeck-client.jar` | зашифрованный клиент (мод) |
| `deffender.exe` | лаунчер |
| `DeffenderUpdater.exe` | апдейтер |
| `bushguard.dll` | нативная защита |
| `bushmeck-libs.zip` | библиотеки клиента |
| `manifest.json` | подписанный манифест обновления |
| `manifest.json.sig` | подпись манифеста |

Ссылки вида
`https://github.com/Pashvot/bushmeck-releases/releases/download/vX.Y.Z/<файл>`
подставляются в переменные `CLIENT_URL` / `LAUNCHER_URL` на сервере.

## Важно

Репозиторий публичный: любой, у кого есть прямая ссылка, может скачать файл. Клиент без
лицензии не запустится, но сам файл доступен. Если это неприемлемо — репозиторий нужно
сделать приватным и раздавать файлы через сервер по подписанным ссылкам.
